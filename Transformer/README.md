# Transformer基本实现

基础的transformers架构，6层模型，pytorch，训练、保存、转onnx、测试

```shell
│  datasets.py          数据集
│  main.py              主程序
│  model.onnx           onnx脚本
│  model.pth            保存的pth文件
│  onnx_1.py            python to onnx
│  print_model.py       打印model
│  README.md   
│  test.py              测试脚本
│  transformer.py       model实现
│  use.py               简单调用
│
└─__pycache__


```

运行：python main.py 

测试：python test.py
